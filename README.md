# JobGuard – Fake Job Detection System

# About the Project

JobGuard is a Machine Learning-based web application designed to detect fake job postings and help job seekers identify fraudulent recruitment activities.

It uses Natural Language Processing (NLP) and Machine Learning techniques to analyze job descriptions and classify job postings as Fake or Genuine.

# Project Objective

The main objective of JobGuard is to protect job seekers from online recruitment fraud by identifying suspicious job postings.

# Features:

- Fake and Genuine Job Detection
- Machine Learning-based Prediction
- Job Description Analysis
- User Registration and Login
- Admin Dashboard
- Job Safety Awareness
- Prediction Results and Reports
- User-Friendly Interface

 # Technologies Used:

# Machine Learning:
- Scikit-learn
- Pandas
- NumPy
- Natural Language Processing (NLP)


# Working Process:

1. User enters job posting details.
2. The application processes the job description.
3. The trained Machine Learning model analyzes the input.
4. The system predicts whether the job is Fake or Genuine.
5. The prediction result is displayed to the user.

 # Project Goal:

To create awareness about fake job postings and make online job searching safer for everyone.
